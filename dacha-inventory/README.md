# dacha-inventory

Учёт запасов на даче: каталог, добавление позиций, история операций и уведомления о
заканчивающихся продуктах. Данные лежат в Supabase (таблицы `products` и `history`,
бакет `products`).

При добавлении позиции приложение само считывает текст с фотографии этикетки и
подставляет название, бренд, год и срок годности в форму.

## Запуск

```bash
npm install
cp .env.example .env     # подставьте значения своего проекта Supabase
npm run dev
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальный сервер разработки |
| `npm run build` | Проверка типов и production-сборка в `dist/` |
| `npm run test` | Тесты разбора этикетки |

## Переменные окружения

| Переменная | Где взять |
| --- | --- |
| `VITE_SUPABASE_URL` | Supabase → Project Settings → API → Project URL |
| `VITE_SUPABASE_ANON_KEY` | Supabase → Project Settings → API → publishable / anon key |

Без них приложение покажет экран «Приложение не настроено» вместо белой страницы.

## Распознавание этикетки

Текст считывается прямо в браузере через [Tesseract.js](https://tesseract.projectnaptha.com/),
поэтому серверу и ключам от внешних сервисов здесь неоткуда взяться и фотография никуда не
уходит. Русская и английская модели (~15 МБ) скачиваются с CDN при первом запуске и дальше
берутся из кеша браузера.

Как устроено:

1. `src/lib/labelOcr.ts` — приводит фото к серому с растянутым контрастом и распознаёт текст,
   возвращая строки вместе с их высотой.
2. `src/lib/parseLabel.ts` — разбирает текст: название (самая крупная строка, не являющаяся
   типовой надписью вроде «содержит сульфиты»), производитель, год урожая, объём, крепость и
   срок годности.
3. `src/pages/AddProduct.tsx` — подставляет найденное в пустые поля формы, не затирая то, что
   уже введено вручную.

Автоподстановку можно выключить галочкой на форме; выбор запоминается в браузере.

Для вина год добавляется к названию (`Мускат белый, 2019`), потому что форма объединяет
позиции по названию, и иначе разные урожаи слились бы в одну карточку.
