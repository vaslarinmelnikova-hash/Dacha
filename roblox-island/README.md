# Остров выживания (Roblox, в стиле Rust)

Прототип выживания: ты появляешься на пляже случайного острова с камнем в руках,
добываешь ресурсы, охотишься на кабанов, крафтишь инструменты, строишь базу
с дверью и ящиком и следишь за голодом. Другие игроки могут тебя убить
и забрать рюкзак.

## Как запустить

1. Скачай файл `build/RustIsland.rbxlx`.
2. Открой его в **Roblox Studio** (File → Open from File).
3. Нажми **Play** (F5). Остров генерируется при старте сервера, поэтому в режиме
   редактирования мир пустой — это нормально.

## Управление

| Действие | Кнопка |
| --- | --- |
| Ударить / добыть / атаковать | ЛКМ с инструментом в руке (`1`, `2`, `3` — выбрать инструмент) |
| Меню крафта | `C` |
| Поесть (сначала жареное мясо, потом ягоды) | `F` |
| Открыть дверь, ящик, рюкзак | `E` рядом с ним |
| Магазин | кнопка «Магазин» справа сверху |

## Что есть в игре

- **Остров** — каждый запуск новый: пляжи, трава, скалы, вода вокруг.
- **Ресурсы** — деревья, камни, кусты с ягодами. Истощаются и вырастают заново.
- **Инструменты** — камень, каменный топор (много дерева), каменная кирка (много камня).
  Топор и кирку держат за низ рукояти, головкой вверх.
- **Кабаны** — бродят по острову. Если ударить, злятся, гонятся и кусают.
  Убитый кабан даёт сырое мясо.
- **Готовка** — встань у костра и выбери в крафте «Пожарить мясо».
  Жареное мясо сытнее ягод и лечит сильнее.
- **Постройки** — костёр (лечит рядом, светит ночью), деревянная стена,
  стена с дверью (открывает только тот, кто её поставил) и ящик
  (открывает только владелец, хранит ресурсы).
- **PvP** — инструменты бьют и других игроков. Отключается в `Config.PvP`.
- **Смерть** — как в Rust: ресурсы выпадают в рюкзак на месте смерти,
  его может забрать любой (рюкзак пропадает через 5 минут). Инструменты теряются.
- **Выживание** — голод падает, на нуле отнимается здоровье.
  Здоровье само не восстанавливается: только еда и костёр.
- **День и ночь** — полный цикл 10 минут.
- **Сохранение** — ресурсы и инструменты сохраняются при выходе из игры
  и автоматически каждые 2 минуты.
- **Магазин** — Game Pass «VIP»: двойная добыча и каменный топор при каждом появлении.

Все числа (урон, добыча, цены крафта, голод, кабаны, размер острова)
лежат в одном файле: `src/shared/Config.luau`.

## Как включить сохранение

Сохранение работает через DataStore, а он доступен только опубликованной игре:

1. В Studio: File → Publish to Roblox.
2. Home → Game Settings → Security → включи **Enable Studio Access to API Services**.

Без этого игра работает, просто прогресс не сохраняется (в Output будет
предупреждение `[PlayerData] Сохранение отключено`).

Постройки и содержимое ящиков не сохраняются: остров каждый запуск новый.

## Как настроить Game Pass

1. Опубликуй игру (см. выше).
2. На [create.roblox.com](https://create.roblox.com) открой игру → Monetization → Passes
   → создай пасс «VIP», включи продажу и задай цену.
3. Скопируй ID пасса и вставь его в `Config.GamePasses` вместо `Id = 0`.

## Структура

```
src/
  shared/Config.luau            настройки, рецепты, еда, Game Pass
  server/Main.server.luau       игроки, удары, крафт, еда, смерть, голод, день/ночь
  server/WorldGen.luau          генерация острова
  server/Resources.luau         деревья, камни, кусты и их добыча
  server/Animals.luau           кабаны: блуждание, погоня, мясо
  server/Tools.luau             модели инструментов и удар
  server/Builds.luau            костёр, стены, дверь, ящик
  server/Containers.luau        ящики и рюкзаки после смерти
  server/PlayerData.luau        инвентарь и сохранение (DataStore)
  server/Shop.luau              проверка и покупка Game Pass
  server/Targeting.luau         поиск цели перед игроком
  client/HUD.client.luau        интерфейс: ресурсы, полоски, крафт, ящик, магазин
  character/Health.server.luau  отключает автолечение
```

## Редактирование кода через Rojo

Код хранится файлами, а в Studio его переносит [Rojo](https://rojo.space):

1. Установи Rojo и плагин Rojo для Studio.
2. В папке `roblox-island` запусти `rojo serve`.
3. В Studio в плагине Rojo нажми **Connect** — изменения файлов сразу попадают в игру.

Пересобрать файл места: `rojo build default.project.json -o build/RustIsland.rbxlx`.
