# Остров выживания (Roblox, в стиле Rust)

Прототип выживания: ты появляешься на пляже случайного острова с камнем в руках,
добываешь дерево, камень и ягоды, крафтишь инструменты, ставишь костёр и стены
и следишь за голодом.

## Как запустить

1. Скачай файл `build/RustIsland.rbxlx`.
2. Открой его в **Roblox Studio** (File → Open from File).
3. Нажми **Play** (F5). Остров генерируется при старте сервера, поэтому в режиме
   редактирования мир пустой — это нормально.

## Управление

| Действие | Кнопка |
| --- | --- |
| Ударить / добыть | ЛКМ с инструментом в руке (клавиша `1`, `2`, `3` — выбрать инструмент) |
| Меню крафта | `C` |
| Съесть ягоду | `F` |

## Что есть в игре

- **Остров** — каждый запуск новый: пляжи, трава, скалы, вода вокруг.
- **Ресурсы** — деревья, камни, кусты с ягодами. Каждый ресурс истощается
  и вырастает заново через некоторое время.
- **Инструменты** — камень (даёт понемногу всего), каменный топор (много дерева),
  каменная кирка (много камня).
- **Постройки** — костёр (лечит, если стоять рядом, и светит ночью) и деревянная стена.
- **Выживание** — голод постепенно падает, на нуле отнимается здоровье.
  Здоровье само не восстанавливается: только ягоды и костёр.
- **Смерть** — как в Rust, всё, что было с собой, теряется; через 5 секунд
  появляешься на новом пляже с камнем.
- **День и ночь** — полный цикл 10 минут.

Все числа (сколько даёт удар, цены крафта, скорость голода, размер острова)
лежат в одном файле: `src/shared/Config.luau`.

## Структура

```
src/
  shared/Config.luau        настройки и рецепты (ReplicatedStorage.Shared)
  server/Main.server.luau   игроки, крафт, голод, день/ночь
  server/WorldGen.luau      генерация острова
  server/Resources.luau     деревья, камни, кусты и их добыча
  server/Tools.luau         модели инструментов и удар
  server/Builds.luau        костёр и стены
  client/HUD.client.luau    интерфейс: ресурсы, полоски, крафт, уведомления
  character/Health.server.luau  отключает автолечение
```

## Редактирование кода через Rojo

Код хранится файлами, а в Studio его переносит [Rojo](https://rojo.space):

1. Установи Rojo и плагин Rojo для Studio.
2. В папке `roblox-island` запусти `rojo serve`.
3. В Studio в плагине Rojo нажми **Connect** — изменения файлов сразу попадают в игру.

Пересобрать файл места: `rojo build default.project.json -o build/RustIsland.rbxlx`.
